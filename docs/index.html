The short version

One finding. For of the deployed high-impact entries, all nine oversight answers are blank. That is % of them.

When.

One recommendation. Record the nine separately, each with an option for does not apply and an option for not yet answered, so a reader can tell a question never put from one with no answer.

US federal agencies publish a list of the AI systems they use once a year, under a White House policy memorandum. The 2025 list holds entries, of which are marked high-impact: the list's own term for a system whose output is the main basis for a decision affecting people. It asks nine questions about how each system is checked, from whether it was tested before use to whether anyone can appeal its decisions. It puts those nine only to the of them that are running, and for of those all nine are blank.

This page sets out what the author would record instead, and shows it working on one entry taken from that list.

    The same form, filled twice

        The second half of this project

        The first three pages read the register as published and say what it can and cannot answer. This page says what the author would build, given that.

        These fields are a proposal, not a finding. What a published register does and does not contain can be checked against the file, and the rest of this site does that. This page cannot be checked the same way. It is one person's judgment about what a register should ask, and nothing here says any organisation is required to ask it.

        Every field comes from something this project found in the published file it read, and each one says whether the US list or the UK standard already asks it. A field that cannot be traced back to that evidence is not here.
