{{publication_duty}} That list is called a use case inventory, or a register. The idea behind it is simple: an organisation cannot oversee what it has never written down.

This page is the register the United States federal government published in 2025. Each row is one system an agency has declared, in the agency's own words. You can search it, narrow it, and open any row to see everything the register records about that system.

The register sets aside nine fields for human oversight, filled in only for the entries it flags high-impact, which are the most serious it records. In most of those entries, all nine are empty.

No entry can be followed from one year to the next

The earlier year's list carries no reference code for any entry at all, so there is nothing to match this year's entries against. Following an entry from one year to the next needs a code that stays the same, and that code is not there.

The 2024 list publishes no identifier for any of its entries.

That is what settles it. Within the 2025 list the picture is better but not whole: of entries, carry no usable identifier, meaning no reference code that would let anyone match this entry to the same system in a later year. Of those, hold the text "TBD" rather than being empty. A further identifier values are used on more than one row, across rows.

An entry without a stable identifier cannot be followed from one year's inventory to the next, whatever else it records. Even an entry carrying one cannot be followed back, because the earlier list has nothing to match it to.
